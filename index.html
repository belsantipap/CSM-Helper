ตัวช่วยกรอก CSM

ติ๊กคะแนนตามใบประเมินที่อยู่ในมือ แล้วให้มันกรอกลง Microsoft Form ให้ · ทำงานในเครื่องคุณทั้งหมด ไม่ส่งข้อมูลออกไปไหน

ติดตั้งครั้งเดียว

1
กด Ctrl+Shift+B ให้แถบ bookmark โผล่ขึ้นมา
2
ลากปุ่มข้างล่างนี้ไปวางบนแถบ bookmark (ลาก ไม่ใช่กด)
กรอก CSM
3
เสร็จแล้ว ใช้ได้ตลอด ไม่ต้องติดตั้งอีก
ถ้าลากไม่ได้ ให้คลิกขวาบนแถบ bookmark → Add page → ช่อง URL วางโค้ดจาก ดูโค้ดเต็ม ข้างล่าง
ใช้บนมือถือ

ส่วน อ่านจากรูปสแกน ตารางติ๊ก ประวัติ และ CSV ใช้บนมือถือได้ทั้งหมด สแกนใน Notes แล้วแนบไฟล์จากหน้านี้ได้เลย

ส่วนปุ่ม กรอก CSM บนมือถือลากวางไม่ได้ ต้องทำแบบนี้แทน:

  • กด ดูโค้ดเต็ม ข้างล่าง แล้วคัดลอกโค้ดทั้งหมด
  • เปิดหน้าอะไรก็ได้ แล้ว เพิ่มเป็น Bookmark / บุ๊กมาร์ก
  • เข้าไปแก้ bookmark นั้น ตั้งชื่อว่า csm แล้วลบ URL เดิมทิ้ง วางโค้ดที่คัดลอกมาแทน
  • เวลาจะใช้: เปิดหน้า MS Form แล้วพิมพ์ csm ในช่องที่อยู่เว็บ จะมี bookmark ขึ้นมาให้กด

ถ้าไม่อยากยุ่งกับ bookmark บนมือถือ: ติ๊กและคัดลอกรหัสในมือถือ แล้วส่งรหัสหาตัวเองทาง Teams หรือ LINE จากนั้นค่อยไปวางที่คอม

สคริปต์นี้ทำอะไร / ปลอดภัยไหม
  • ทำงานเฉพาะตอนคุณกดปุ่ม บนแท็บที่เปิดอยู่เท่านั้น ไม่ได้รันเบื้องหลัง
  • ไม่ส่งข้อมูลออกนอกเครื่อง ในโค้ดไม่มีการเรียกเว็บปลายทางใด ๆ
  • มองแท็บอื่นไม่ได้ อ่านรหัสผ่านที่เซฟไว้ไม่ได้ อ่านไฟล์ในเครื่องไม่ได้
  • ไม่ใช่ส่วนขยาย ไม่ได้ติดตั้งอะไรลงเครื่อง เป็น bookmark ธรรมดา ลบทิ้งได้ตลอด
  • กรอกเสร็จแล้วเด้งกล่องให้ตรวจหัวกระดาษก่อน — PO, ชื่องาน, ผู้รับเหมา — กด "ส่งเลย" ถึงจะส่ง ไม่กดเองโดยพลการ
